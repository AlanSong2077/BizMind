# Titanic test run — 2026-10-18

This archive records a real DeepSeek-driven BizMind run using source commit
`c9c3111`. Three experiment rounds completed, with 60 code executions and 58
successful prediction scores. The independent local evaluator measured the best
accuracy as **152 / 179 = 0.8491620111731844**.

## Model and validation

- Training: 712 passengers; validation: 179 passengers; prediction: 418 passengers.
- Fixed stratified 80/20 split, random seed 42, reused across all rounds.
- Winning model: equal-weight probability blend of LogisticRegression and ExtraTrees.
- LogisticRegression: L2 penalty, `C=1.0`, `max_iter=2000`, `random_state=42`.
- ExtraTreesClassifier: 400 trees, depth 6, minimum 4 samples per leaf, seed 42,
  `n_jobs=4` on CPU.
- Feature engineering: name-derived title, family size and alone flag, alongside
  passenger attributes; training-fitted imputation, scaling and one-hot encoding.
- Prediction threshold: probability >= 0.5 means survived.
- This is a local validation score. The official test labels were unavailable.

DeepSeek (`deepseek/deepseek-flash`) planned experiments and generated code. The
sklearn models performed the training and predictions. API credentials are absent
from this archive.

The initial worker incorrectly split the already-split training data, producing
143 validation predictions. The evaluator rejected that output; subsequent cells
used the correct 179 validation inputs. One inspection cell returned no prediction
files. These account for the two code executions without valid prediction scores.
Failures and regressions remain in the archived logs.

The LLM-assembled first-round script omitted the final ExtraTrees blend. Therefore
`winning_cell.py`, extracted from actual first-round cell 20, is the reproduction
reference. It was replayed in a fresh process without LLM calls, reproduced the
score, and generated byte-identical test predictions. Generated reports and
conversations retain the model's original wording; `summary.json` and
`replay_verification.json` contain the independently checked facts.

Later worker logs contain inherited parent history. Their `executed_cells.json`
files include only that worker's own cells. The original logger removed non-ASCII
characters; this archive preserves the text that was actually recorded.

Absolute project and home-directory paths were replaced with `<PROJECT_ROOT>` and
`<USER_HOME>`. Paths inside original reports refer to the original run layout.
Raw input datasets, private validation labels, binary model files, environment
files and kernel connection files are excluded.

## Reproduce without an API key

Install the project dependencies and place the official Titanic CSV files in
`data/titanic/` as described in
[the local test instructions](../../../examples/titanic_description.md).
Run these commands from the project root, using a fresh replay directory:

```sh
archive=test_runs/titanic/2026-10-18-deepseek
replay=workspace/titanic-replay
mkdir -p "$replay/source/train_data" "$replay/source/predict_data" "$replay/working/work"
cp data/titanic/train.csv "$replay/source/train_data/train.csv"
cp data/titanic/test.csv "$replay/source/predict_data/test.csv"
.venv/bin/python "$archive/evaluation/split_dataset.py" --input_dir "$replay/source" --public_dir "$replay/input/data" --private_dir "$replay/private"
cp "$archive/winning_cell.py" "$replay/working/winning_cell.py"
(cd "$replay/working" && ../../../.venv/bin/python winning_cell.py)
.venv/bin/python "$archive/evaluation/evaluate.py" --public_dir "$replay/input/data" --private_dir "$replay/private" --pred "$replay/working/work/val_predictions.csv"
cmp "$archive/predictions.csv" "$replay/working/predictions.csv"
```

Expected accuracy: `0.8491620111731844`. A successful `cmp` prints nothing.
